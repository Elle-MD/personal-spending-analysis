# Family Expense Analysis & Visualisation

A personal end-to-end data project covering the full workflow: from raw data collection and cleaning to interactive dashboards.

## The project includes a PDF with:
- Project overview and data model
- Spending overview dashboard (categories, day-of-week patterns, main retailer share)
- Shopping items and loyalty points dashboard (frequently bought items, items by price per unit/kg, loyalty points)

## Tools used:
- **Data sources:** Bank exports (Excel) + shopping tickets (PDF & paper)
- **Data cleaning:** Power Query (Excel & Power BI)
- **Data model:** Multi-source model with a shared date dimension
  - *One table is independent as it uses keyword matching in Power Query rather than a direct table relationship.*
- **Visualisation:** Power BI

## Period covered: 
January – early April 2026

## Key findings:
- 20% of household spending concentrated at a single retailer
- Fish has the highest cost per unit among regularly purchased items
- Shopping behaviour varies significantly by day of the week
